# مافيا

لعبة مافيا جماعية بـ Flutter، للويب والجوال والكمبيوتر.

**صفحة التحميل:** https://abdallah4f7.github.io/mafia/

## طريقة اللعب
- **اللعب مع بوتات:** تحدد عدد البوتات والمافيا (1 إلى 3). تشتغل على جهازك وبدون إنترنت في نسختي الأندرويد والمتصفح بعد فتحها.
- **دخول عشوائي:** تدخل أكثر غرفة فيها لاعبين، وإذا ما فيه غرفة تنفتح لك غرفة جديدة. إذا مرت دقيقة بدون 5 لاعبين، تكمّل البوتات الأماكن.
- **إنشاء لعبة:** تحدد العدد والمافيا، وتبدأ أنت اللعبة إذا صاروا 5 لاعبين أو أكثر.
- **السيرفرات:** تدور الغرفة من القائمة أو تدخل بالكود.
- **لعب على جوال واحد:** تسجلون أسماءكم وتحددون المافيا، والجوال يدور بينكم لمعرفة الأدوار والتصويت السري. في الليل تغمضون عيونكم، وينادي الصوت والكتابة المافيا ثم الدكتور ثم الشايب. الصوت يحتاج صوت عربي على الجهاز، والكتابة تظهر دايم. ما يحتاج إنترنت بعد فتح اللعبة.

الأدوار: مافيا، طبيب، شايب، مواطن. تقدر تكتب أي اسم، حتى لو كان مستخدم، ورقم المقعد يفرق بين اللاعبين.

## كيف يشتغل الأونلاين
جهاز منشئ الغرفة هو اللي يدير اللعبة، وSupabase Realtime ينقل الرسائل فقط بدون أي تخزين:
- إذا طلع منشئ الغرفة تنتهي اللعبة عند الكل.
- كل لاعب يوصله دوره على قناة خاصة فيه، لكن جهاز منشئ الغرفة عنده كل الأدوار في الذاكرة، وهذا مو محمي من شخص يعدل البرنامج.

الإعدادات في [lib/config.dart](lib/config.dart).

## التطوير
أدوات أندرويد والمحلل ما تشتغل على مسار فيه حروف عربية مثل «سطح المكتب»، فاشتغل من مسار إنجليزي:

```
flutter test                                   # الاختبارات
$env:LIVE='1'; flutter test test/online_live_test.dart   # اختبار على Supabase الحقيقي
flutter build apk --release
flutter build web --release --base-href /mafia/app/ --pwa-strategy=none   # انسخ الناتج إلى docs/app
cd desktop; npm install; npm run dist          # ملف تشغيل Windows
```

نسخة الكمبيوتر نافذة Electron تفتح نسخة الويب، فأي تحديث في `docs/app` يوصلها تلقائيًا.

## إطلاق إصدار جديد
اللعبة تقرأ [docs/version.json](docs/version.json) عند الفتح وكل 30 دقيقة، وإذا كان رقمه أكبر من اللي فيها تعرض إشعار التحديث.

1. غيّر الإصدار في `pubspec.yaml` و`lib/update_check.dart` و`desktop/package.json`.
2. ابنِ النسخ وارفعها في Release جديد.
3. آخر شيء، غيّر `docs/version.json` وارفعه، عشان ما يوصل الإشعار قبل ما يتوفر الملف الجديد.
